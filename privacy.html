Privacy policy

muzammil-backup is a private tool used by a single shop owner to copy backup files of the shop's own records to the owner's own Google Drive.

  • It accesses only the owner's Google Drive, and only to store and read these backup files.
  • It does not collect, sell, share or send any data to anyone else.
  • The sign-in token is stored only on the owner's computer.
  • Access can be removed at any time from the Google account's security settings.
